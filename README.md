# On View (oV) 🚀

A sleek, full-stack social profile application with a modern, customizable UI. Built from scratch with vanilla HTML/CSS/JS and a lightweight Node.js/Express backend.

## CLICK TO VIEW: https://kasi-code.github.io/on-view/

## ✨ Features

- **Modern UI/UX:** Beautiful dark/light mode with smooth CSS animations and glass-morphism styling.
- **Custom Authentication:** Register, login, and delete accounts. (Usernames are case-insensitive; passwords remain strict).
- **Dynamic Profiles:** Users can edit their display name, username, password, and Date of Birth.
- **Work Experience Editor:** Add, edit, and delete multiple job titles and descriptions directly from the settings menu.
- **Cross-Device Preferences:** Theme preferences (Dark/Light) are saved to the server and persist across devices.
- **Custom Notifications:** Replaced ugly browser alerts with custom, sliding "Toast" notifications and confirmation modals.
- **Responsive Design:** Fully functional on desktop and mobile devices.

## 🛠️ Tech Stack

**Frontend:**
- HTML5
- CSS3 (Custom properties, Flexbox, CSS Grid, Keyframe animations)
- Vanilla JavaScript (ES6+, Fetch API, LocalStorage)
- Font Awesome (Icons)
- Google Fonts (Montserrat)

**Backend:**
- Node.js
- Express.js (v5)
- File System (`fs`) for lightweight text-based data storage (`user.txt`)
